

# Fix: Replace Incorrect Variables in AEA Ignite Pipeline

## Problem Summary

The AEA Ignite pipeline (`0393efea-a3c2-48f1-8087-278e7da3fbc4`) uses the wrong variable name `{{researchSummary}}` in 7 out of 14 steps. This is **not blocking** report generation but severely **degrading quality** because the AI receives literal text `{{researchSummary}}` instead of the actual user's research summary.

## Evidence

**Steps with Wrong Variable (`{{researchSummary}}`):**

| Step | Name | Impact |
|------|------|--------|
| 1 | nrf_alignment_mapping | Missing project context |
| 2 | market_need_quantification | Missing project context |
| 3 | tam_sam_som_analysis | Missing project context |
| 4 | competitor_and_alternative_benchmarking | Missing project context |
| 5 | ip_landscape_review | Missing project context |
| 7 | partner_stakeholder_mapping | Missing project context |
| 8 | technical_feasibility_benchmarking | Missing project context |

**Steps with Correct Variable (`{{summary}}`):**
- Step 0: build_source_pack (working correctly)

**Result:** The AI completes steps but returns many "Unknown" values because it doesn't know what the research is actually about.

## Root Cause

The pipeline was auto-generated by `process-grant-guidelines` when it used the wrong variable names (`{{researchSummary}}` instead of `{{summary}}`). Although we fixed the generator, existing pipelines still have the old incorrect variables.

## Solution

Update the 7 affected prompt templates in the database to replace `{{researchSummary}}` with `{{summary}}`.

## Technical Implementation

Run a SQL update to fix all affected steps:

```sql
UPDATE prompt_bundle_steps
SET prompt_template = REPLACE(prompt_template, '{{researchSummary}}', '{{summary}}')
WHERE bundle_id = '0393efea-a3c2-48f1-8087-278e7da3fbc4'
  AND prompt_template LIKE '%{{researchSummary}}%';
```

## Files to Modify

This is a **database-only fix** - no code changes required.

| Target | Change |
|--------|--------|
| `prompt_bundle_steps` table | Replace `{{researchSummary}}` → `{{summary}}` in 7 steps |

## Validation

After the fix:
1. Start a new report run
2. Verify Step 1+ receives the actual research summary (not literal `{{researchSummary}}`)
3. Check that outputs contain meaningful data instead of "Unknown"
4. The report quality should significantly improve

## Impact

- **Current behavior:** AI receives `"Identify the problem this technology ({{researchSummary}}) solves"` → outputs "Unknown"
- **After fix:** AI receives `"Identify the problem this technology (AMT Bio is developing novel biologics...) solves"` → outputs real analysis
